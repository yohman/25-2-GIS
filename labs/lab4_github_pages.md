
# Lab 4: GitHub Pages を使って Web 地図を公開しよう

このラボでは、GitHub Pages を使って、自分の作成した Web 地図（Week3）をインターネット上で公開します。公開されたURLをクラスのPadletに投稿して共有します。

---

## ✅ ステップ 1：GitHub Pages を有効化しよう

1. ブラウザで自分の GitHub リポジトリを開く（Week2とWeek3で使ったリポジトリ）
2. 上部タブの「Settings（設定）」をクリック
3. 左側のメニューから「Pages」もしくは「Pages」セクションを探す
4. 「Source」で以下を選択：
   - ブランチ（branch）：`main`
   - フォルダ：`/ (root)` または `docs`（※Week3のファイルがある場所に合わせて選ぶ）
5. 「Save」ボタンをクリック
6. 数秒〜数分後に公開用のURLが表示される（例：`https://username.github.io/repo-name/`）

---

## ✅ ステップ 2：Week3 の地図を公開しよう

1. `index.html` と `style.css` を含む `week03` フォルダが GitHub にアップロードされていることを確認
2. GitHub Pages が有効になっていることを確認
3. ページが表示されるURLは：
   - `https://あなたのユーザー名.github.io/リポジトリ名/week03/`

ブラウザでアクセスし、地図が正しく表示されるか確認しましょう。

---
